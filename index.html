CLASSROOM RESOURCE · YEARS 7–8

Humanities LA Toolkit

  • Ready-to-use reading prompts and sentence-writing practice for LAs to use in class.
  • Adapt the activities to suit the student or group you’re working with.
  • Each skill includes a worked example to guide you.
Start here
  • Choose one skill and one small goal.
  • Model it aloud, try it together, then give the student a similar turn.
  • If needed, read aloud, shorten the text or let the student rehearse their answer orally.

What can I do right now?

When no task has been set for you, choose the situation that fits.

The teacher is explaining the task

Listen for the first instruction. When students begin, quietly check that the learner knows where to start.

“What’s the first thing you need to do? Show me where you’ll start.”
A student hasn’t started

Find out what’s holding them up. Read the first instruction together, explain one key word or help them find the right part of the text.

“Which bit is tricky right now? Let’s look at that part together.”
A student can explain an idea but hasn’t written it

Ask them to say one complete sentence aloud, write it and read it back. Use the Forming a sentence card in Writing if they need a model.

“Tell me your idea first. Now say it as one whole sentence.”
There’s no task set for me

Check with the teacher when there’s a natural pause. If they’re happy for you to work with a student, pick one reading skill and use a short piece of the class text. Model one, try one together, then give the student a turn.

“I’ll show you how I find a clue. Then we’ll find one together.”
Students are working independently

Check back with a student you’ve already supported. See if they can use the same strategy on their next question.

“Show me how you got started on this one.”

When to step back

Give the student a moment to think, offer one prompt, then let them try. Once they’re underway, check back in a few minutes.
